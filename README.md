# 光华楼风洞享受者 🌬️

一款手绘涂鸦风的竖版飞升小游戏：操纵复旦校徽小球，借光华楼间峡谷的狂风与风柱节节攀升。

## 玩法

- **按住屏幕左右半边**（手机）或 **←/→ / A/D 键**（电脑）横移
- 上升全靠吃风柱：钻进**窄缝中心**升力翻倍
- 每连过 **5 根风柱**触发「超级加速」：无风期也能持续托升
- 撞墙不会立刻死：进入 2 秒受伤状态（校徽变红闪烁），**期间再撞一次**才出局
- 狂风与滑翔交替：狂风托升，滑翔期靠固定减速度飘行、横移躲避杂物

## 运行

纯静态页面，零依赖零构建：任意静态托管（GitHub Pages / Netlify 等）或直接双击 `index.html` 即可游玩，支持手机触屏。

## 技术

原生 Canvas 2D + WebAudio 程序化音效，无任何框架与外部资源（校徽以 base64 内嵌）。手感参数集中在 `game_v2.js` 顶部的 `PARAMS` 表。
